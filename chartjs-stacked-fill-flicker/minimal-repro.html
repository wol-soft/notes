Two datasets, fill: 'stack', stacked y axis, Chart.js 4.5.1. Toggle representation triggers an animated update whose y-axis tick labels change width, so every point's x animates a few pixels. Near the end of that animation the orange band (dataset 1) disappears for a few frames. The log below reports every frame where it has 0 pixels in the sampled column. Deterministic buttons do the same without any animation: they nudge one point's x by 1e-9 px (or by 1e-3 px for contrast) and redraw.
